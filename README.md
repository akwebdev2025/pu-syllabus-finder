# PU Syllabus Finder

Mobile-first Panjab University syllabus finder.

## Features
- Search
- Faculty filtering
- Programme filtering
- Academic year filtering
- Category filtering
- Semester filtering
- Dark mode
- Direct official syllabus links
- GitHub Actions automatic data updates

## Data source
https://puchd.ac.in/nep-syllabus.php

Always verify the latest syllabus on the official PU website.
